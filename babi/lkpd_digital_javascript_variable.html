D. APERSEPSI

Bayangkan kamu sedang membuat aplikasi data siswa. Program perlu mengetahui data: Nama siswa ("Budi"), Kelas ("XI RPL 1"), Umur (16), Nilai (85), Jurusan.

Jawaban Dugaan Awal Siswa:

Untuk menyimpan informasi tersebut di dalam program, kita dapat menggunakan konsep Variable. Variable bekerja sebagai wadah penyimpan nilai di memori komputer yang diberi nama penanda. Contoh penulisan kodenya:

let namaSiswa = "Budi";
let kelas = "XI RPL 1";
let umur = 16;
let nilai = 85;

E. AKTIVITAS 1 - MENGAMATI

// Kode JavaScript yang diamati: 
let nama = "Budi";
let umur = 16;
let nilai = 85;

console.log(nama);
console.log(umur);
console.log(nilai);
Browser Developer Console
> Budi
> 16
> 85
1. Apa yang ditampilkan pada Console?

Console menampilkan nilai dari ketiga variable secara berurutan pada baris terpisah, yaitu: Budi, 16, dan 85.

2. Menurutmu, apa fungsi nama, umur, dan nilai?

Ketiganya berfungsi sebagai **nama variabel (identifier)** yang bertindak sebagai label/wadah untuk menyimpan data berupa teks nama, angka umur, dan angka nilai di dalam memori program.

3. Apa yang terjadi jika kode console.log(nama); dijalankan tanpa membuat variabelnya terlebih dahulu?

Akan terjadi kesalahan error: Uncaught ReferenceError: nama is not defined karena komputer tidak menemukan variabel bernama 'nama' di dalam memori.

4. Menurut dugaanmu, apa yang dimaksud dengan variable?

Variable adalah lokasi penyimpanan di memori komputer yang diberi nama penanda untuk menyimpan data (seperti teks atau angka) agar nilainya dapat dipanggil, digunakan, atau diubah kembali oleh program.

H. AKTIVITAS 4 - EKSPERIMEN UBAH DATA

// Pengubahan Data Sesuai Identitas Siswa Hira:
let nama = "Hira abiguna ramadhan";
let kelas = "X PPLG 2";
let umur = 16;
1. Apakah hasil pada Console berubah?

**Ya, berubah.** Nilai keluaran pada console langsung menyesuaikan dengan data teks baru yang kita gantikan.

2. Bagian kode mana yang kamu ubah?

Bagian **nilai data (value)** yang berada di sebelah kanan tanda sama dengan (=), yaitu mengubah string "Budi" menjadi "Hira abiguna ramadhan", "XI RPL 1" menjadi "X PPLG 2".

3. Mengapa program dapat menampilkan data yang baru?

Karena nilai variabel dapat diperbarui di dalam memori. Saat console.log() dieksekusi, komputer akan membaca dan mengambil nilai paling terbaru yang tersimpan di dalam variabel tersebut.

J. AKTIVITAS 6 - MENGENAL let DAN const

// Menggunakan let (Nilai dapat diubah)
let umur = 16;
umur = 17; // Diubah
console.log(umur);
> Hasil: 17
// Menggunakan const (Konstanta Tetap)
const nama = "Budi";
nama = "Andi"; // Error!
console.log(nama);
> TypeError: Assignment to constant variable.

Tabel Perbandingan Keyword:

Keyword Nilai dapat diubah? Kegunaan Sederhana
let Ya (Dapat diubah) Untuk data variabel yang nilainya masih mungkin berubah (contoh: umur, nilai, stok).
const Tidak (Tetap / Konstan) Untuk data yang nilainya tetap dan tidak perlu diubah (contoh: nama sekolah, tanggal lahir).

K. AKTIVITAS 7 - ATURAN PENAMAAN VARIABLE

Diperbolehkan:

  • let nama;
  • let namaSiswa; (camelCase)
  • let nama_siswa; (underscore)
  • let nilai1; (angka di belakang)

Tidak Diperbolehkan:

  • let 1nama; (diawali angka - Error)
  • let nama siswa; (ada spasi - Error)
  • let nama-siswa; (pakai strip/dash - Error)
